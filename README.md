#  DocBot — Ask Your Documents Anything

An AI-powered document assistant built with Python and Groq.

## What it does
- Upload any PDF document
- Ask questions about it in plain English
- Get instant AI-powered answers based on the document content

## Tech Stack
- Python
- Streamlit
- Groq API (Llama 3.1)
- PyPDF2

## How to run
1. Clone the repo
2. Run `pip install streamlit groq pypdf2`
3. Add your Groq API key to a `.env` file
4. Run `streamlit run app.py`
